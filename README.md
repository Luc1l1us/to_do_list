# to_do_list

A personal task and note management application inspired by Google Keep, built with Flutter, Express.js, and MongoDB.

## Overview

To-Do List is a personal project inspired by Google Keep, exploring the development of a self-managed alternative to traditional note-taking and task management applications.

The motivation behind this project was to explore building an application that provides a familiar note-taking experience while giving users greater control over their own data, with privacy and data ownership as key considerations.

The application uses Flutter for its frontend, Express.js for its backend, and MongoDB for data storage.

## Tech Stack

### Frontend

    Flutter
    Dart

### Backend

    Node.js
    Express.js

### Database

    MongoDB

## Features

Task and note management

## Project Status

This project is no longer actively maintained. Development was discontinued before all originally envisioned functionality could be implemented.

The repository is preserved as a record of my development experience and exploration of Flutter application development, REST API integration, and database management.
